# wealth-building

A practical knowledge base for understanding how wealth is built, grown, and preserved through financial strategies, asset ownership, compound growth, reinvestment, leverage, cash flow management, and intelligent capital allocation. Learn the principles, analyze real-world examples, and turn financial knowledge into actionable strategies.

## Repository approach

Each skill documents one wealth-building strategy found in a video, article, book, or other source. Skills should preserve the source's core idea, explain the mechanism, identify assumptions, and distinguish illustrative examples from verified financial results.

New skills can be added independently as new sources are reviewed.
